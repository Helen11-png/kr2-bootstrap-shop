# Контрольная работа №2

Тема: «CSS-фреймворки: разработка интерфейса на Bootstrap или альтернативном CSS-фреймворке».

**Студент:** ФИО, группа
**Дисциплина:** Фронтенд и бэкенд разработка (РТУ МИРЭА, ИПТИП)

## Описание

SuperTutor — учебный многостраничный сайт каталога курсов и репетиторов. Это вторая реализация той же предметной области, что и в КР №1 (`kr1-html-css-shop`), но интерфейс полностью построен на Bootstrap 5: сетка, навигация, карточки, формы, модальное окно и другие компоненты. Собственный CSS сведён к минимуму (`css/custom.css`).

## Используемый фреймворк

Bootstrap 5.3.8.

## Подключение Bootstrap

Bootstrap подключён **локально, без CDN**. Файлы фреймворка лежат в папке `vendor/bootstrap/`:

- `vendor/bootstrap/css/bootstrap.min.css`;
- `vendor/bootstrap/js/bootstrap.bundle.min.js`.

Порядок подключения в каждой странице: сначала `bootstrap.min.css`, затем `css/custom.css`; скрипты (`bootstrap.bundle.min.js`, затем `js/main.js`) — перед закрывающим `</body>`.

## Реализованные Bootstrap-компоненты

- Сетка: `container`, `container-fluid`, `row`, `col-12 col-md-6 col-lg-4`, отступы `g-4`;
- `navbar` (с кнопкой-«бургером» на мобильных, единая на всех страницах);
- `card` (курсы, преимущества, боковые блоки);
- `btn` и варианты: `btn-primary`, `btn-outline-primary`, `btn-light`, `btn-outline-secondary`;
- `badge` (метки «Популярное», «Новинка», «Идёт набор»);
- `alert` (акция, информация, сообщение об успешной отправке, «ничего не найдено»);
- `modal` (быстрая заявка);
- формы: `form-control`, `form-select`, `input-group`, `form-check`, валидация `needs-validation`;
- `accordion` (частые вопросы), `nav-tabs` (вкладки курса), `carousel` (слайдер на главной);
- `toast`, `breadcrumb`, `list-group`, `table`;
- utility-классы: отступы (`my-*`, `p-*`, `mb-*`), `text-*`, `bg-*`, `shadow-sm`, `rounded`, `h-100`, `d-grid`, `gap-*`, `sticky-lg-top`.

## Самостоятельные доработки

- Bootstrap подключён локально (папка `vendor/`), а не через CDN.
- Дополнительная страница `contacts.html`.
- Дополнительные компоненты: carousel, tabs, accordion, toast, breadcrumb.
- Рабочие фильтры каталога (категория и диапазон цены) на `js/main.js`, счётчик найденных курсов и сообщение «ничего не найдено».
- Модальное окно заявки автоматически подставляет курс, с карточки которого оно открыто.
- Форма заявки: валидация средствами Bootstrap и HTML5, маска телефона `+7 (900) 000-00-00`, предмет подставляется из ссылки (`order.html?course=math`), нельзя выбрать дату в прошлом.
- Единая фирменная палитра из КР №1 задана в `css/custom.css` через переопределение переменных Bootstrap.

## Как проверить

1. Открыть `index.html` в браузере (сервер не нужен).
2. Сузить окно или включить режим мобильного устройства в DevTools: колонки перестраиваются, меню сворачивается в «бургер».
3. В каталоге выбрать «Новинки» или ввести цену «До 1000» — список карточек обновится.
4. Нажать «Заказать» на любой карточке — откроется модальное окно с выбранным курсом; отправить пустую форму — появятся подсказки валидации.
5. На странице курса переключить вкладки и раскрыть вопросы в accordion.
